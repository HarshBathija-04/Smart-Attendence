### 3. FACE RECOGNITION

**Q: How does face recognition work in your system?**

**A:** Face recognition works in three steps:

1. **Face Detection:** Uses HOG (Histogram of Oriented Gradients) algorithm to locate faces in the image

2. **Face Encoding:** Generates a 128-dimensional numerical vector (embedding) that uniquely represents the face using a deep learning model (ResNet)

3. **Face Comparison:** Calculates Euclidean distance between the captured face encoding and stored encodings. If distance < 0.5, it's a match

---

**Q: What is the accuracy of your face recognition?**

**A:** The system achieves:
- 96% accuracy in good lighting
- 83% accuracy in poor lighting
- 90% overall average accuracy

The face_recognition library itself achieves 99.38% on the Labeled Faces in the Wild benchmark.

---

**Q: What is face encoding?**

**A:** Face encoding is a 128-dimensional numerical vector that represents the unique features of a face. It's generated by passing the face image through a deep neural network trained to recognize faces. Two faces of the same person will have very similar encodings.

---

**Q: What is the threshold value you used?**

**A:** I used a threshold of 0.5 (Euclidean distance). This means:
- If distance < 0.5: Faces match (same person)
- If distance >= 0.5: Faces don't match (different persons)

This value provides a good balance between accuracy and false positives.

**Q: How does your system prevent proxy attendance?**

**A:** Security is implemented through:

---

**Q: What is JWT?**

**A:** JWT (JSON Web Token) is a compact, URL-safe token format used for authentication. It contains:
- Header (algorithm type)
- Payload (user data, expiration)
- Signature (for verification)

The token is sent with each API request to verify the user's identity.

---

**Q: Why use bcrypt for passwords?**

**A:** bcrypt is used because:
1. It's a one-way hash function
2. It automatically handles salt generation
3. It's slow by design (resistant to brute force)
4. It's widely accepted as secure
5. It has adjustable work factor (rounds)
